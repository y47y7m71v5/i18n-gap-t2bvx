i18n-gap — 多语言 JSON 缺 key 扫描

对照基准语言扫描 locale JSON，列出缺失的 key（适合 CI）

仓库
y47y7m71v5/i18n-gap-t2bvx
快速开始 
git clone https://github.com/y47y7m71v5/i18n-gap-t2bvx.git
cd i18n-gap-t2bvx
node bin/scan.js ./locales --base en
中转实测 · 59API 兼容入口

串 agent 前先 curl /models。我可复现环境把 OPENAI_BASE_URL 指到 https://59api.com；你换成自建前，用同一套检查清单验收。

https://59api.com · OpenAI-compatible

环境变量示例（OpenAI 兼容中转） 
# 测评环境：OpenAI 兼容中转（59API）
# 先 curl https://59api.com/v1/models 再绑 Claude Code / Codex / SDK
export OPENAI_BASE_URL=https://59api.com/v1
export OPENAI_API_KEY=sk-your-key
